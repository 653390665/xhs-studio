# 抖音采集插件（XHS Studio）

在抖音作者主页捕获作品清单，发送到本地 XHS Studio，走现有的「下载 → 转写 → 对标集 → 蒸馏」链路。

## 为什么是插件

抖音的 `aweme/v1/web/aweme/detail/` 由 Argus WAF 保护：需要 `UIFID` cookie、`a_bogus`/`X-Bogus` 签名和页面上下文。服务端直连返回 403；yt-dlp 也在源码里承认没有签名实现。唯一稳定的路径是让请求发生在真实浏览器页面里。

## 安装

1. Chrome 打开 `chrome://extensions/`；
2. 右上角开启「开发者模式」；
3. 「加载已解压的扩展程序」选择本目录；
4. 打开本地应用（默认 `http://127.0.0.1:8000/platforms/xhs/assets/douyin`），
   在「浏览器采集」卡片生成令牌；也可以用页面上的「打开插件目录」直接定位本目录；
5. 点扩展图标，粘贴令牌，保存，点「测试连接」。

## 使用

1. 打开任意抖音作者主页（`https://www.douyin.com/user/...`）；
2. 点右下角「采集这个作者」；
3. 可选填关键词（会使用页面里的「搜索 Ta 的作品」）；
4. 设置最多条数（默认 20）；
5. 开始。插件会逐条取详情（间隔 1.2 秒），然后创建本地采集任务；
6. 到应用「研究 → 抖音采集」看任务进度，完成后「导入对标集」。

## 限额

- 单次最多 40 条（默认 20）；
- 每条间隔 1.2 秒；
- 同一作者 10 分钟内只允许采一次（插件侧冷却）；
- 时长 15–75 秒由服务端过滤；已采集过的作品自动跳过。

## 已知限制

- 抖音页面结构会变；如果「找到 0 条」，先在页面里切到「作品」标签，或填关键词再试。
- 详情接口可能返回 HTML（风控）；刷新页面、确认登录后再试。
- 插件不下载视频，只发送清单；下载与转写由本地后端完成。
